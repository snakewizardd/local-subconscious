# Miscellaneous Experiments

This directory preserves runnable side experiments that are related to Local
Subconscious but are not part of its production path. Each experiment must
document its possible connection to the project, its current limitations, and
the evidence needed before it should move into core code.

## Experiments

- [`lattice_explorer/`](lattice_explorer/README.md) - explores exact alignment
  between bounded, even-numbered checkpoints in integer-related cadences. It
  may inform periodic job coordination and future temporal resurfacing work.
